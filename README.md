# きょうの服装

天気予報から、今日（朝に開いた場合）または明日と今夜の寝間着（就寝前に開いた場合）の服装をアドバイスする Web アプリです。

## 動かし方
ES Modules を使うため、ファイルを直接開くのではなく、ローカルサーバー経由で開きます。

```bash
python3 -m http.server 8080
# ブラウザで http://localhost:8080/ を開く
```

- `http://localhost:8080/?hour=7` … 朝の画面を確認
- `http://localhost:8080/?hour=22` … 就寝前の画面を確認

## ホーム画面に追加（PWA）

- **Android（Chrome）**: 公開 URL を開き、右上の「︙」→「ホーム画面に追加」または「アプリをインストール」
- **iPhone（Safari）**: 公開 URL を開き、共有ボタン →「ホーム画面に追加」
  - ホーム画面のアプリは Safari とデータが別。追加後にもう一度、地域の設定をする
  - ホーム画面のアプリは、Safari の「7 日使わないとデータを消す」対象外（WebKit 公式ブログ）

電波がないときは、前回取得した天気で表示する（画面上部に「○時点の天気」と出る）。
`sw.js` で保存するファイルを増減したら、`CACHE_VERSION` を上げる。
